# Changelog

Every change to Platehouse is recorded in `CHANGELOG.md` at the root of the source repository,
newest version first, in the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.
Platehouse follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Read it before you upgrade: each version lists what was added, changed and fixed, and anything you
need to do. See [Backups and upgrades](./backups-and-upgrades.md#upgrading).

0.1.0 is the first release.
